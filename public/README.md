# Public Assets Guide

Add the following files to this folder:

## Required Files

### 1. **profile.jpg** (or .png)
- Profile photo for your homepage hero section
- Recommended: 600x600px minimum
- Aspect ratio: Square (1:1)
- File should be placed: `/public/profile.jpg`

### 2. **resume.pdf**
- Your professional resume in PDF format
- This will be linked from the resume page
- Clicking "View PDF Resume" will open it in a new tab
- File should be placed: `/public/resume.pdf`

## Optional Files

You can add more images for:
- Swimming photos (`/public/swimming-hero.jpg`)
- Project screenshots (`/public/projects/project-name.jpg`)
- Background images

## How To Add Files

1. Create a `profile.jpg` file and place it in the `/public/` folder
2. Create or export your resume as `resume.pdf` and place it in the `/public/` folder
3. Restart the dev server (if running)
4. The portfolio will automatically use these files

## Generated Resume PDF

If you don't have a PDF of your resume yet, you can:
1. Use Google Docs and export as PDF
2. Use MS Word and export as PDF
3. Use an online resume builder
4. Open the resume page locally and use "Print to PDF"

Your resume information is already displayed beautifully on the `/resume` page!
